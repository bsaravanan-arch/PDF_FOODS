# PDF_FOODS
This repo contains the automation code of PDF Foods

## GitHub automation template (first-time setup)

If you are adding automation to this repository for the first time:

1. Use the workflow file at `.github/workflows/first-time-automation-template.yml`.
2. Update the `Run placeholder automation command` step with your real build/test/deploy commands.
3. Commit and push your changes. The workflow can be run manually from **Actions** (`workflow_dispatch`) and will also run on pushes and pull requests to `main`.
